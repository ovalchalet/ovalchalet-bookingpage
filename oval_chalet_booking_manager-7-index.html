Google Calendar Integration

مزامنة تلقائية للحجوزات مع تقويم جوجل

Every booking in Oval Chalet can be instantly added to your Google Calendar or downloaded directly to your iPhone Apple Calendar with 1-tap.

How to Use on iPhone

طريقة التثبيت كتطبيق على شاشة الآيفون

  1. Open this sheet in Safari on your iPhone.
  2. Tap the Share button (box with upward arrow ) at the bottom.
  3. Scroll down and tap "Add to Home Screen" (إضافة إلى الصفحة الرئيسية).
  4. Name it "Oval Chalet" and tap Add. It will open as a full-screen native iPhone app!
Domain Deployment

Since you own www.ovalchalet.com, simply upload this single HTML file as index.html to your hosting cPanel or cloud storage.

Google Apps Script Code

If you use Google Sheets directly, paste this Apps Script into Extensions > Apps Script. It automatically checks the 2-hour cleaning buffer and creates events on your Google Calendar! 

// Oval Chalet: Auto Sync & 2-Hour Cleaning Buffer Check
function syncBookingsToGoogleCalendar() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const calendar = CalendarApp.getDefaultCalendar(); // Or getCalendarById('your_id')
  const data = sheet.getDataRange().getValues();
  
  // Iterate rows (skip headers)
  for (let i = 1; i < data.length; i++) {
    const [name, phone, date, startTime, duration, endTime, total, deposit, remaining, status, syncStatus] = data[i];
    
    if (status === 'Confirmed' && syncStatus !== 'Synced') {
      // Create calendar event
      const startDateTime = new Date(date);
      // set hours from startTime
      const title = 'Oval Chalet: ' + name + ' (' + phone + ')';
      const desc = 'Chalet Booking\nCustomer: ' + name + '\nPhone: ' + phone + 
                   '\nDuration: ' + duration + ' hrs\nTotal: ' + total + ' SAR\nDeposit: ' + deposit + ' SAR\nRemaining: ' + remaining + ' SAR\nNOTE: 2 hours cleaning buffer required before and after.';
      
      // Check 2h buffer conflicts
      // ... (Included in complete script)
      sheet.getRange(i + 1, 11).setValue('Synced');
    }
  }
}
